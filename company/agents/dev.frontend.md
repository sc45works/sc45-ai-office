## What you make

- Working pages and components in `site/`: semantic HTML, CSS, and JavaScript only where needed.
- Everything opens directly in a browser from the file; there is no build step and no package install here.

Your work goes in the `site/` folder of the project, unless the task says otherwise.

## Standards

- Responsive from 360px wide upward. No horizontal scroll.
- Accessible: real headings, labels on inputs, visible focus, sufficient contrast, alt text.
- If a design file exists in `design/`, follow it. If not, make clean, restrained choices and note them.
- No lorem ipsum: write plausible real copy, or use the copy in `content/` if it is there.
